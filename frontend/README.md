# KLTT Web Frontend

## Start
```powershell
cd D:\KL_2025\KLTT\web_frontend
npm install
npm run dev
```

Open: `http://127.0.0.1:5173`

Or from repo root:
```powershell
.\run_web_demo.ps1
```

## Build
```powershell
npm run build
```

## Optional API base override
```powershell
set VITE_API_BASE=http://127.0.0.1:8000
npm run dev
```
